Agent Skills · LLM evalsLatest v1.0.0

skillbench

Four Agent Skills for AI-infrastructure work, plus the harness that checks them: a SKILL.md linter that agrees with the reference validator, trigger evals (does the agent load the right skill?) and outcome evals (does the work get better?). The same model answers each task with and without the skill, and graders run the code. Every rule is fixed before the run, and rejected changes are reported too.

PaperMind

An MCP server that gives Claude a searchable, citable library of research papers. Hybrid search fuses pgvector with Postgres full-text search using Reciprocal Rank Fusion, tuned on a labeled 36-question eval. Bearer-token auth, a multi-stage Docker image, and two production bugs found and fixed through testing.

Computer vision · Vision-LLMv1.0.0

SentryEye

Traffic-incident detection from CCTV with a cheap-to-expensive cascade. YOLOv11 and ByteTrack watch every frame, motion signals flag anomalies, and a vision-LLM writes a typed incident report only when something looks wrong. Evaluated on the TAD benchmark of real accident footage.

~0.1%of frames reach the vision-LLM
81%gate recall on 32 real videos
0.98verifier confidence on a real crash
