Agent Skills · LLM evals · v1.0.0

skillbench

Four Agent Skills for AI-infrastructure work, plus the harness that checks them: a SKILL.md linter that agrees with the reference validator, trigger evals (does the agent load the right skill?) and outcome evals (does the work get better?). The same model answers each task with and without the skill, and graders run the code. Every result is pre-registered, and rejected changes are reported too.

Computer vision · Vision-LLM · v1.0.0

SentryEye

Traffic-incident detection from CCTV with a cheap-to-expensive cascade: YOLOv11 and ByteTrack watch every frame, motion signals flag anomalies, and a vision-LLM writes a typed incident report only when something looks wrong. Evaluated on the TAD benchmark of real accident footage.
